# pilgrimhousekids.com

The Pilgrim House Kids website: three static pages served by GitHub Pages.

- `index.html` — what the app is
- `privacy.html` — the privacy policy, the same wording the app shows in its Parents area
- `support.html` — the support page the App Store listing points at

English and Brazilian Portuguese on every page, with a switch at the top right.

## Two rules for this repository

**No tracking, ever.** No analytics, no embeds, no third-party scripts, not even a
web font served from someone else's domain. The app's privacy policy promises that
nothing is collected; a site that quietly contradicted it on the very page making
the promise would be the first thing a careful parent noticed.

**The privacy policy's wording is not edited casually.** It is a public promise, and
the same text appears inside the app. Change one and the other has to change in the
same breath.

## Fonts

`fonts/` holds Fraunces and Alegreya Sans, self-hosted rather than loaded from
Google. Both are SIL Open Font License and their licences sit beside them. The
fallback stacks are written out in full, so the pages stay readable if a file is
ever missing.

## Editing

The pages are generated by `build-site.py`, which lives with the app project —
edit there and regenerate rather than hand-editing the HTML, or the next build
quietly undoes you.
